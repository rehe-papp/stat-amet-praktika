## Getting Started

1. Install dependencies:

    ```bash
    npm ci
    ```

2. Start development server:

    ```bash
    npm run dev
    ```

3. Open in browser:

- http://localhost:3000

4. Open `app/page.tsx` and edit to customize.


5. Run Playwright E2E tests:
    - Install playwright, if you haven't done so

        ```bash
        npx playwright install
        ```
    - Run tests

        ```bash
        npx playwright test
        ```
